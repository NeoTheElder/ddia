# DDIA — interactive study notes

Self-contained interactive HTML artifacts for every chapter of *Designing Data-Intensive Applications* (Martin Kleppmann) — 1st-edition structure with 2nd-edition (2025) updates folded in. Each chapter page has Feynman-style explanations of every concept, figures, click-through animations, cross-references to other chapters, core takeaways, and an MCQ quiz with an explained answer key.

- `chapters/` — one self-contained HTML file per chapter; open in any browser.
- `chapters/index.html` — the hub: book map, part/chapter cards. Root `index.html` just redirects to it (so the bare Pages URL works).
- `reference/` — the book PDF (gitignored) and extracted TOC.
- `docs/wayfinder/ddia-learning/` — the [wayfinder map](docs/wayfinder/ddia-learning/MAP.md) driving this effort: decisions made, tickets open.

Live at **https://neotheelder.github.io/ddia/** (GitHub Pages, `master` branch root). The files are self-contained, so `file://` browsing works identically.
