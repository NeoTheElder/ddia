Designing Data-Intensive Applications

Interactive study notes on Martin Kleppmann's book — one self-contained page per chapter, with click-through animations, cross-linked concepts, and quizzes. Personal reference · not affiliated with the author

Each chapter page walks every section of the book in order: Feynman-style explanations, hand-drawn figures, steppers you can click (or arrow-key) through, backward/forward cross-references with hover definitions, core takeaways, and an MCQ quiz with an explained answer key. The 1st edition's 12-chapter structure is kept; what the 2nd edition (2025) changed is folded in as marked asides on every page.

HOW TO READ THESE PAGES One color language runs through all twelve chapters: ember = the write path — mutation, appends, derivation — and cyan = the read path — lookups, queries, consumers. Dotted-underline terms are cross-references: hover for the definition, click to jump to the chapter that owns the concept. Every animated figure is a story told in steps — click next, or focus the figure and use ← →. Quizzes grade in place; the answer key explains the distractors too.
